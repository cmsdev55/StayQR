# On-Page SEO (score 80)

## What works
- Unique titles, none over 60 chars
- One H1 per page
- Descriptions on all pages

## Findings
### Medium: Long industry descriptions
8 descriptions run 165–204 characters.

**Fix:** Trim to about 155.

### Low: Double brand in titles
'About StayQR · StayQR' and 'Contact StayQR · StayQR'.

**Fix:** Use absolute titles.

### Low: Duplicate description
/login repeats the homepage description.

**Fix:** Write a login-specific description.
